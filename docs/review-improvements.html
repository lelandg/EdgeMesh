    Review record

    Scope & verification

    Verified fixes are listed below. They are local working-tree changes; the selectable proposals above are future work. Existing personal settings and Notes were preserved. EdgeMesh and the nested MeshTools repository have separate fix branches; neither has been committed or published.

    Verified bug fixes

    • Startup and image actions. Fresh configuration no longer crashes; failed image loads preserve the current image; Save handles missing and all-black images and reports write failures.
    • Preview and edge detection. Grayscale previews stay in memory. Grayscale/BGRA edges and BGR luminance handling are consistent with OpenCV.
    • Depth inference. DPT receives a prepared input; Hugging Face models and tensors share the selected device; processors are reused; image colors, output dimensions and flip alignment are corrected.
    • Background removal. Tolerance bounds do not wrap at black/white; selected RGB colors match BGR pixels; border-connected background masking preserves foreground holes.
    • Smoothing. Integer maps use floating-point diffusion, opposite borders do not influence one another, and constant maps normalize without invalid division.
    • Mesh solidification. Flat and mirrored backs stitch only boundary edges with consistent winding. Duplicate faces and collapsed seam triangles are removed; vertex colors survive.
    • Viewport and export. Rotation follows the currently loaded mesh. Export checks the active mesh and file extension; STL uses supported binary output; failed writes reach the error handler.
    • Contour extrusion. Complete quad walls now close each contour; separate shapes stay disconnected, degenerate projection triangles are skipped, and failed output writes are reported. These are lateral surfaces without caps.
    • Logging and installer paths. UI errors also go to rotating per-user logs; named loggers stay independent. Install scripts resolve their files from the repository location.

    Validation: 43 regression tests passed (33 EdgeMesh + 10 MeshTools). Tests were run before and after fixes. Real PLY and STL files were exported and reopened; a real Qt window started offscreen with a fresh temporary configuration. Selection controls, category filtering, draft restoration and JSON import were checked in the browser; the JSON download action was exercised.

    Limits: Full pretrained-model downloads, CUDA inference, interactive GPU rendering, hardware controllers and packaged Windows builds were not exercised. The offscreen startup emitted existing optional-color and missing-demo-image messages when launched outside the repository. Self-intersecting or non-manifold input meshes still require validation. Edge-only extrusion creates side walls, not capped solids. No exhaustive absence-of-bugs claim is made.

    Proposals are grounded in edge_mesh.py, depth_to_3d.py, log_utils.py, the dependency files, and docs/CodeMap.md. MeshTools is a separate repository and needs its own change review.

    AI references: Transformers SAM2 documentation and Transformers Depth Anything V2 documentation. Links open only when clicked. GPU memory and speed claims are intentionally left for local measurement.
