Launch EdgeMesh

Run the desktop app from this checkout with one PowerShell command. uv must be installed. The first run downloads Python dependencies; model downloads and assistant authentication are configured separately in the app.

These commands use the local implementation at D:\Documents\Code\GitHub\EdgeMesh. Python 3.12 is selected for the supported native wheels. The source has not been published to PyPI.

Launch the desktop with depth and the optional assistant SDK

uvx --python 3.12 --exclude-newer "1 week" --from "D:\Documents\Code\GitHub\EdgeMesh[depth,assistants]" edgemesh

Launch the base image, mask and contour workspace

uvx --python 3.12 --exclude-newer "1 week" --from "D:\Documents\Code\GitHub\EdgeMesh" edgemesh

Check the command without starting a window

uvx --python 3.12 --exclude-newer "1 week" --from "D:\Documents\Code\GitHub\EdgeMesh[depth,assistants]" edgemesh --help

Show offline depth-diagnostic options

uvx --python 3.12 --exclude-newer "1 week" --from "D:\Documents\Code\GitHub\EdgeMesh[depth,assistants]" edgemesh diagnose-depth --help

Install a persistent app command

uv tool install --python 3.12 --exclude-newer "1 week" "D:\Documents\Code\GitHub\EdgeMesh[depth,assistants]"

Launch after persistent installation

edgemesh
