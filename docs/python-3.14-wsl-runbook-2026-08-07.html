Python 3.14 on WSL, side by side.

Install the newest Python 3.14.x on WSL Ubuntu 24.04 without touching the system 3.12. EdgeMesh must stay on 3.12 — Open3D 0.19.0 ships no wheels past cp312, so 3.14 goes in alongside, not instead.

01 /

Before you start

Open3D blocks EdgeMesh from 3.14. As of today, PyPI's latest Open3D is 0.19.0 with wheels for CPython 3.8–3.12 only. If EdgeMesh's interpreter moves to 3.13+, pip install open3d fails and the 3D viewport dies. Also: a 3.14.7 patch release could not be confirmed to exist — the commands below install the newest 3.14.x actually published (currently 3.14.0 in uv's registry).

System today

Ubuntu 24.04.3 LTS on WSL2. System python3 → 3.12.3, plus a 3.10 remnant. Do not repoint the python3 symlink — apt tooling depends on 3.12.

Path A — uv

Recommended. Per-user install, no sudo, exact-version pinning, instant venvs. uv is already installed at ~/.local/bin/uv.

Path B — deadsnakes

Traditional apt route via the deadsnakes PPA. Gives a system-wide python3.14 binary. Needs sudo, so you run it yourself.

02 /

Path A — uv (recommended)

Four commands, no sudo. Step 1 refreshes uv so its Python registry knows the newest 3.14.x patch; step 2 installs it.

1 · Update uv itself

uv self update

2 · Install the newest Python 3.14.x

uv python install 3.14

To pin an exact patch instead (only if it exists in uv python list): uv python install 3.14.7

3 · Verify

uv run --python 3.14 -- python --version

4 · Make a 3.14 venv anywhere you want one

uv venv --python 3.14 ~/.venvs/py314 && ~/.venvs/py314/bin/python --version
03 /

Path B — deadsnakes PPA (apt)

Run these yourself in the WSL terminal — they need sudo. Installs python3.14 system-wide next to 3.12; the default python3 is left alone.

1 · Add the deadsnakes PPA

sudo add-apt-repository ppa:deadsnakes/ppa -y

2 · Refresh package lists

sudo apt update

3 · Install Python 3.14 + venv + headers

sudo apt install -y python3.14 python3.14-venv python3.14-dev

4 · Verify

python3.14 --version
04 /

EdgeMesh stays on 3.12

Per the project's AGENTS.md, EdgeMesh needs Python ≤ 3.12 until Open3D publishes cp313/cp314 wheels. While you're here, this creates the missing .venv_linux the agent-side house rules expect, pinned correctly:

Create EdgeMesh's WSL venv on 3.12

uv venv --python 3.12 /mnt/d/Documents/Code/GitHub/EdgeMesh/.venv_linux

Install EdgeMesh requirements into it

uv pip install --python /mnt/d/Documents/Code/GitHub/EdgeMesh/.venv_linux -r /mnt/d/Documents/Code/GitHub/EdgeMesh/requirements.txt

When Open3D ships a cp314 wheel, re-run the first command with --python 3.14 to migrate. Check with: curl -s https://pypi.org/pypi/open3d/json | grep -o 'cp31[34]' | sort -u
