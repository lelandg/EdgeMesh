EDGEMESH / YOUR SELECTED IMPROVEMENTS

A more responsive, repeatable image-to-mesh workflow.

The ten selected improvements are implemented in this checkout. Mesh-health checks and model downloads start disabled. Suggestions and subject masks take effect only after you accept them.

Validation boundary
Local CPU geometry, provider-contract and offscreen Qt tests pass. Real downloaded-model inference, GPU execution, a native OpenGL session, standalone packaging and a fresh hosted CI install still need validation.

Start with an image

  1. Load an image and adjust its preview. Grayscale and transparent inputs are converted consistently; the source file stays intact.
  2. Choose a depth model. Cached Hugging Face models run offline. For an uncached model, review Models → Review model licenses and download details, then explicitly enable downloads. Local MiDaS/DPT source and checkpoints have their own registration dialog.
  3. Generate. Progress appears in the status bar. Cancel job requests cancellation after the active stage; changing source or processing settings invalidates that result. A previously accepted mesh remains available.
  4. Export Mesh to the destination and format you choose. Generated work files are temporary; export before closing.

New controls

SESSION

Save work and reuse settings

Save session records the source reference, settings, model identity, accepted mask and recent generation history. Open session can relocate a missing image. Presets contain reusable settings. Use Ctrl+Z and Ctrl+Shift+Z for settings and mask undo/redo; regenerate to update geometry.

AI ASSISTANCE

Local parameter suggestions

Suggest local parameters explains bounded recommendations based on image statistics and shows current/suggested image previews. Depth and smoothing changes apply on the next generation. Review, apply, or cancel. Image content is not sent to a service.

AI ASSISTANCE

Keep a subject

Select subject with SAM2 opens a proportional image preview. Add foreground/background points or a box and run segmentation. Use brushes to refine or draw a mask without loading a model. Accept the overlay to apply it to the next depth mesh; cancel preserves the previous mask.

MESH · OPTIONAL

Inspect and repair deliberately

Check mesh health before export is optional and initially off. You can inspect on demand. Preview conservative repair compares counts before and after cleanup; Apply accepts it, Cancel leaves it unchanged, and Undo mesh repair restores the prior mesh. Holes are not filled.

MODELS

Reuse verified identities

Model/processor pairs are reused by revision, device and preprocessing settings. Downloads use the recorded revision. Unload cached models releases the in-process cache when jobs are idle. Model changes and session restoration wait until active work finishes cancelling.

SUPPORT

Portable settings and diagnostics

Settings, logs, presets and temporary work live in your user data directory. Legacy settings are copied once and the original is preserved. Errors appear in the app and rotating logs. Export sanitized diagnostics creates a metadata bundle without raw logs, config values or source images.

Details and limits

Where is my work stored?

On Windows, application state lives under %LOCALAPPDATA%\EdgeMesh. macOS uses Application Support; Linux uses XDG state storage. EDGEMESH_DATA_DIR can override the root. Model manifests are under models; Hugging Face retains its normal model download cache. Successful job output is removed when superseded or the app closes. Exported files and saved sessions are separate.

What does a session preserve?

A session references its original image; it does not embed that image or a mesh. It preserves settings, accepted mask and model metadata. The in-app undo stack is bounded; saved processing history records recent successful runs. Open a session, relocate the source if necessary, and generate to recreate geometry. A model's exact files must still be available locally or downloaded with your permission.

What do the AI features require?

Parameter suggestions use deterministic local statistics. SAM2 inference requires an optional model; manual brush masks do not. Depth Anything V2 Large has a noncommercial license, Depth Pro uses Apple's model license, and SAM2 uses Apache 2.0. Review the linked model cards in the app before selecting a model for your work. No weights were downloaded during implementation.

What was selected?

Background jobs, model caching, optional mesh validation, sessions, data contracts, user state, reproducibility/CI, code map, subject masking and local parameter suggestions. Model comparison, uncertainty overlays and multiview reconstruction were not selected.
