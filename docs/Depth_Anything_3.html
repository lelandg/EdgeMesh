What each option adds

ModelUse
SmallFirst trial and lowest model size among these choices.
BaseA larger general depth model to compare with Small.
Mono-LargeA model dedicated to single-image relative depth.
Metric-LargeMetric depth estimation used here as a normalized relief.

DA3 distance values are converted to inverse depth before creating the relief. Near surfaces rise above far surfaces, while colors keep their source-image positions. If you generated a DA3 mesh before this correction, restart the app and generate the mesh again.

Reliefs do not preserve metres or camera calibration. This integration does not combine multiple photographs or generate unseen object surfaces.

Existing runtime and troubleshooting

An existing DA3 environment can be selected with the EDGEMESH_DA3_PYTHON environment variable before starting the app. Setup errors are recorded in the EdgeMesh data directory under logs/da3-setup.log. Inference errors are recorded in the per-user logs. Cancel stops the separate worker.

The separate runtime is necessary because DA3 requires NumPy below 2 and the GUI uses NumPy 2. Models reload for each job, which adds startup time and releases their memory when the job ends. The locally verified runtime uses the CPU. CUDA and accelerated xformers kernels were not validated.
